## 👨‍💻 Sobre mim

Sou estudante de **Ciência da Computação na UFC Campus Crateús** e Engenheiro de Software Full-Stack apaixonado por resolver problemas reais com código limpo e bem arquitetado.

Além do desenvolvimento web tradicional, atuo em **pesquisa aplicada de Inteligência Artificial** com foco em Visão Computacional médica — segmentação volumétrica 3D de imagens usando arquiteturas como U-Net, SegResNet e Swin UNETR.

- 🎓 Estudante de Ciência da Computação — **UFC**
- 🔭 Pesquisando **Deep Learning para Visão Computacional médica**
- 🚀 Desenvolvendo projetos **Full-Stack** com Python, Java e React
- 🌍 Crateús, Ceará, Brasil
- 💡 Apaixonado por **Clean Code** e boas práticas de engenharia

## 🚀 Projetos em Destaque

### 🔬 Segmentação Volumétrica 3D — Pesquisa em IA (UFC)
> Pesquisa aplicada em Deep Learning para segmentação automática de seios paranasais em imagens médicas 3D.
> Implementação e comparação de U-Net, SegResNet e Swin UNETR com K-fold validation.

### ⛏️ MineFlow — ERP para Extração Mineral (Pedreiras)
> Sistema Full-Stack para automação e gestão do ciclo de vida de fios diamantados. Cálculo dinâmico de rendimento (m²/h), controle de maquinário e análise de produtividade.
> Desenvolvido com Python (Django), React, PostgreSQL e orquestrado em Docker.

### 🌐 Portal da ACIC Crateús — Projeto Integrador *(em desenvolvimento)*
